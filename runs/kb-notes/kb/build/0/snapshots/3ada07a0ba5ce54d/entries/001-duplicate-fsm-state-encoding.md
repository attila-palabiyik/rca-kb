# Duplicate state encodings in a Verilog FSM

When a case-based state machine stalls or never asserts an output associated with a later state, compare the numeric encodings of its named states. Distinct names can resolve to the same value. If two case items match, the first one runs, so the later state's branch is unreachable.

In the five-state Moore `TopModule` task, `S2` and `S3` both used encoding 2. The `S2` branch's transition to `S3` therefore left the register at encoding 2, and the next clock still used the `S2` branch. Changing only `S3` to encoding 3 matched the reference on all 261 grading samples. An Icarus Verilog simulation also exercised all ten state/input combinations and confirmed that `flag` was high only in `S4` and cleared on active-low reset.

In the overlapping `1011` detector `TopModule`, the same collision prevented the FSM from recognizing the `101` prefix. The submission and reference changed only `S3` from `2` to `3`, and all 153 grading samples matched. Icarus Verilog verified two one-cycle pulses for `10110111`, the one-clock delay from the last bit of each match, and asynchronous reset while `flag` was high. All 4,096 12-bit streams also passed a sliding-window check. A detector can fail its overlap example because it never reaches the match state, so confirm each matched prefix has a unique encoding before changing fallback transitions.

Compare the encodings after applying both the literal width and the state register width. In the six-bit `011100` detector, the failure state `sf6` used `4'd20`, which truncated to `4'd4` and collided with `s4`. The reference fix changed only `sf6` to the unused encoding `4'd12`. The submitted fix also switched both combinational blocks to `always @(*)` and simplified the reset condition. It matched all 1,215 grading samples and passed an Icarus Verilog check of all 4,096 ordered pairs of six-bit groups plus asynchronous resets. Checking back-to-back groups exercises the transitions out of both result states as well as the timing of each verdict.
