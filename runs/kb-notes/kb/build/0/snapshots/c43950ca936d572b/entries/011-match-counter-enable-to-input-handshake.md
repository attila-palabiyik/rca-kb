# Match the counter enable to the input handshake

In the one-bit-to-six-bit serial-to-parallel `TopModule`, the shift register captured on `ready_a && valid_a`, but the counter held on `~ready_a && ~valid_a`. With either input low by itself, the counter advanced or wrapped without capturing a bit. The reference changed only the counter's hold condition to `~ready_a || ~valid_a`, the complement of the shift register's capture condition.

The submission corrected the counter behavior as part of a rewrite that also tied `ready_a` high and pulsed `valid_b` only when the sixth bit was accepted. Its Icarus test passed all 64 word patterns with gaps and reset, but the grader reported 16 mismatches in 151 samples. The test encoded the rewritten timing. The reference leaves `ready_a` low during reset and raises it on the first rising clock edge after release. It also keeps `valid_b <= cnt == 5`, so an idle edge with a pre-edge count of five asserts `valid_b` even though `data_b` holds. The grading result gives the aggregate mismatch count without a per-signal breakdown.

In a separate task with the same one-bit-to-six-bit `TopModule`, the hold predicate already used `~ready_a || ~valid_a`, but the counter wrapped at 4. The output logic read the pre-edge count and expected 5, which the counter could never reach. The reference changed only the wrap count from 4 to 5. The submitted rewrite made that correction, tied `ready_a` high, and gated `valid_b` on acceptance of the sixth bit. Its Icarus tests passed all 64 word patterns with gaps and reset, and the grader reported 16 mismatches in 151 samples. The reference diff confirms it preserved the original ready and valid timing described above. The grading result does not attribute individual mismatches to either signal.

In a third task, the counter enable and wrap count were correct, but `valid_b` decoded `cnt == 5` combinationally. The reference moved that same predicate into a rising-edge block with active-low asynchronous reset. This samples the pre-edge count on the same edge as the existing `data_b` register. The submitted rewrite registered the flag, added a `valid_a` gate, and tied `ready_a` high based on the prose description. Icarus passed all 64 word patterns, including stalls before the sixth bit and asynchronous reset, under the rewritten contract. Grading again reported 16 mismatches in 151 samples, with no per-signal breakdown. The reference diff confirms that an idle edge after five accepted bits still asserts the flag with held data and that reset still clears `ready_a`. In this converter, the request to fix the timing bug called for preserving those observable behaviors even though the prose suggested a different handshake.

For a counter that tracks accepted inputs, trace both the advance condition and the reachable pre-edge counts. Check that its enable agrees with the storage enable and that its wrap count agrees with the downstream completion predicates. If the required fix is localized, test that change against the existing cycle timing, including reset release and an idle edge at the terminal count. A test built around rewritten handshake timing can pass every data pattern and still miss a timing difference.
