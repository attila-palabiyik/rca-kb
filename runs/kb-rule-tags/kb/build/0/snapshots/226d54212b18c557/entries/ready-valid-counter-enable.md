Advance a ready/valid beat counter only when both signals are high, preserving the existing reset and output timing when the bug is isolated to the counter enable.

Applies to counters that track accepted transfers, including interfaces whose ready signal becomes high after reset. In the 1-to-6-bit serial-to-parallel `TopModule`, the reference changed the count hold condition from `~ready_a && ~valid_a` to `~ready_a || ~valid_a`. This preserved the registered `ready_a` that reset low and the registered `valid_b` based on `cnt == 5`. The submitted rewrite tied `ready_a` high and asserted `valid_b` only on the sixth accepted beat. It passed its directed Icarus tests and differed from the reference on 16 of 151 samples. The grading report did not identify which changes caused the individual mismatches.
