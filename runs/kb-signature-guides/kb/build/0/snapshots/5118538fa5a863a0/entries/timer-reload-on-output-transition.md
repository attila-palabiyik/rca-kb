# Timer reload on a registered output transition

Use this guide when the FSM reaches the intended phase but its timer loads late, reloads throughout the phase, or stops counting after an override ends. In a design with pipelined outputs, record the values immediately before a sampling edge and the results after the nonblocking assignments settle.

1. Run through the first affected phase with overrides disabled. Check the FSM destinations, then compare the timer load condition with the corresponding conditions for phases that work. In the traffic light controller's `TopModule.sv`, the red → green → yellow → red destinations were already correct. The red and yellow loads used `!red && p_red` and `!yellow && p_yellow`. Green used `green && p_green`.
2. Identify which register leads. Here `green <= p_green` copies the buffer into the visible output. Before the edge that turns green on, `green` is 0 and `p_green` is 1. The reference changed the reload predicate to `!green && p_green`, so the timer loads 60 on the same edge the output turns on. With the original predicate, the timer fell from 1 to 0 on entry and then loaded 60 repeatedly while both registers were high and no pedestrian override took priority.
3. Check the cycles around entry and the override threshold. In the reference, the red-to-green state change takes the counter from 3 to 2, and the light buffer changes as the counter reaches 1. The next edge produces visible green with a count of 60, followed by 59 with no request. A request sampled during green above 10 loads 10. A request held through 10 allows the counter to proceed to 9. Compare the timer and light outputs together at each edge.

Source task involved `TopModule.sv`, a traffic light controller with a pedestrian request and a green timer reload polarity bug. The submitted rewrite passed its own tests for the prose specification but differed from the grading reference on 220 of 517 samples. It also changed the reset light outputs from all off to red immediately and replaced the registered light stages. The supplied reference preserved the original reset and register stages, added the missing negation to the green reload predicate, and removed the trailing timing comment. When the prose and the surrounding circuit imply different timing, include a waveform check of the localized fix so the observable differences are explicit.
