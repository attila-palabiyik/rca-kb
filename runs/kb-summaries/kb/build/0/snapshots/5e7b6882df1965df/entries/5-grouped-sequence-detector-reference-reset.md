# Reset behavior in a combinational FSM output decoder

This entry records the grading result for the six-bit 011100 detector in entry 4. The submitted solution replaced the clocked outputs with direct equality assignments on the registered terminal states, using a wildcard combinational block. Its local Icarus test passed all 4,096 adjacent group pairs and reset checks after a delay. Grading failed with one mismatch across 1,215 samples. The result did not identify the mismatching input or sample time.

The reference preserves the original transition logic and changes the output block from clocked to combinational with explicit sensitivity to pstate, data, and rst_n. Its first branch drives both outputs low when rst_n is low. The next branches drive the verdict for s6 or sf6, and the final branch drives both low. With a known state and reset deasserted, both implementations decode the same terminal states on the sixth edge. The submitted decoder relied on the asynchronous state register reaching idle to clear the verdict. In simulation, this can leave a verdict visible until the nonblocking state update, whereas the reference decoder can respond to the reset event directly. Direct equality assignments can also propagate X from an indeterminate state where the reference if/else chain takes its default branch. Neither distinction was established as the cause of the grading mismatch.

For similar FSM repairs, trace the output dependencies that existed before moving a block from clocked to combinational logic. Retain explicit reset priority and known defaults when the original outputs have those properties. A test that observes outputs after a delay verifies settled behavior. A separate check can cover startup with an uninitialized state and distinguish reset-driven output changes from changes caused by the state register update.
