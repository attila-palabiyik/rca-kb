# Check the enable shared by registered data and valid

**Check** whether the valid pulse and the output register update sample the same completion condition on the same clock edge. Compare the full set of counter or state values, the input-valid guard, and whether each path is clocked or combinational.

- **The completion count is unreachable or occurs on the wrong transfer.** [Check the counter's wrap point](transfer-counter-wrap.md) before changing the output enables.
- **The conditions differ, and the flag is defined as a pulse on a new word load.** Align the valid condition with the data load. Accept an input before the word is complete, then stall on an edge where the next accepted input would complete a word. Neither edge should assert output valid. Resume input and verify that the word and valid pulse appear together.
- **The conditions differ, and the flag is defined as a sampled count or state.** Register its existing predicate if timing is the defect. On a stall at the matching count, check the flag and data separately. The flag can assert or stay high while the data register holds. Preserve the input handshake and its reset timing unless the diagnosis calls for changing them.
- **The conditions agree but sample different cycles.** When the interface calls for valid to accompany a newly registered word, register the flag on the data load edge using the pre-edge completion condition. Check both sides of the edge that accepts the final input beat. The flag should assert together with the new word after that edge.
- **The conditions and sample cycles agree.** If the pulse is still early or late, trace the cycle of each operand in the [completion condition](combined-condition-timing.md). If the pulse timing is correct but the word is wrong, trace the data slices used on the load edge.

**Observed in `TopModule.sv`**, a 24-bit to 128-bit stream converter. The data register loaded a word when the pre-edge count was 5, 10, or 15 and `valid_in` was high. The valid register combined the count match and `valid_in` with OR, allowing pulses on ordinary input beats and during stalls at a completion count. The reference fix changed OR to AND. The submitted implementation also reorganized the clocked logic and narrowed the shift register from 128 to 120 bits. It matched all 261 graded samples. The reference diff shows that the valid expression alone was sufficient.

**Observed in another `TopModule.sv` task for the same width converter**, the input-valid guard and two completion counts agreed, but `valid_out` used count 12 where `data_out` used count 10. With a valid input at count 10, the word loaded without a valid pulse. At count 12, valid asserted while the data register held its previous word. Changing 12 to 10 in the valid expression matched all 261 graded samples and was the complete reference fix.

**Observed in a third `TopModule.sv` task for the same width converter**, the completion counts and input-valid guard already agreed. The combinational `valid_out` followed the live counter and `valid_in`, and the clocked `data_out` loaded using their pre-edge values. The flag could assert before the completing input was accepted and drop after the counter advanced on the load edge. Registering `valid_out` with the existing predicate and active-low asynchronous reset was the complete reference fix and matched all 261 graded samples.

**Observed in `TopModule.sv`**, a six-bit serial-to-parallel converter with a correct handshake counter and a combinational `valid_b`. The reference fix moved `valid_b` into a rising-edge block with active-low asynchronous reset and kept its predicate `cnt == 5`. At count 5, an edge with `valid_a` low can therefore assert `valid_b` while `data_b` holds. The reference also kept `ready_a` registered, low in reset and high after the first rising edge out of reset. The submitted implementation registered `valid_b` with an added `valid_a` guard and tied `ready_a` high. Its local tests passed, but 16 of 151 graded samples differed. The grading supplied the reference diff and gave no per-change attribution for the mismatches.
