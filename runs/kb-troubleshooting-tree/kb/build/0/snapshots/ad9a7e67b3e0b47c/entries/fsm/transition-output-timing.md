# Check how a state transition reaches registered outputs

**Check** which edge updates each register between a next-state decision and the observable outputs. For each edge, use the values present before the edge to evaluate the nonblocking assignments. Include any counter reload condition that reads those registers.

- **A combinational result asserts on entry to the match state, and the specification calls for a pulse on the following edge.** Register the match-state decode using the current state on the rising edge. Apply the specified reset to the output register. Check the output after the edge that samples the final bit and after each of the next two edges to verify the delay and pulse width.
- **The outputs and counter reload already line up.** Keep the existing trigger and register stages when correcting a next-state destination. Check the last count in the old state and the first count in the new state.
- **A combinational output copies the buffered phase bit used by an entry guard such as `!red && p_red`.** The visible and buffered bits settle to the same value between edges, so the guard cannot detect entry. Register the visible outputs from the buffered bits. Check that the guard is true on the edge that updates the visible outputs and reloads the timer, and false on the following edge.
- **The outputs and counter reload land on different edges.** If the reload compares a visible light with its buffered value, go to [the phase-entry reload check](phase-entry-reload.md). If the discrepancy occurs during reset or startup, go to [the output decode and reset check](output-decode-reset.md).

**Observed in `TopModule.sv`**, an overlapping `1011` detector with an early flag. The combinational decode asserted `flag` on the edge that sampled the final `1` and entered `S4`. The reference registered `state == S4` with an asynchronous active-low reset. The register reads `S4` on the following rising edge, so for `10110111` the pulses occur just after edges 5 and 8, one clock after matches ending at bits 4 and 7. The output-only change passed all 153 grading samples. Checking the overlap count alone would miss the timing bug because the original decode also produced two pulses.

**Observed in `TopModule.sv`**, a traffic-light FSM with incorrect red and green destinations. The grading reference changed red to advance to green and green to advance to yellow. It kept the comparison at 3 and retained both output register stages and the original reset behavior. On an ordinary countdown, the edge sampling 3 updates the FSM state and produces count 2. The next edge updates the buffered lights and produces count 1. The following edge sees the difference between the buffered and visible lights, updates the visible lights, and reloads the timer on that same edge. The original comment predicted a visible count of 0, which the reload logic skips on this path.

The submitted rewrite changed the destinations, removed the register stages, and drove red during reset. Its local tests passed against that interpretation of the prose, but 220 of 517 graded samples differed from the reference. The grade gives an aggregate for the rewrite, so it does not isolate the failures attributable to reset or any other individual change.

**Observed in `TopModule.sv`**, a traffic-light FSM with correct state destinations and reload guards, but a combinational copy from the buffered lights to the visible lights. The reference registered the visible lights on the rising edge, cleared all three on asynchronous reset, and kept the idle reset state and the state transition at count 3. On a steady-state transition, the edge sampling count 3 changes the state, the edge sampling 2 changes the buffered lights, and the edge sampling 1 changes the visible lights and reloads the counter together. After reset, the first edge with `p_red` high and visible `red` low both asserts red and reloads 10. The submitted rewrite instead started in red and changed phase at count 1 without the buffered stages. Its tests passed against the prose reset requirement, while 220 of 517 graded samples differed from the supplied reference. The aggregate does not identify which differences caused individual mismatches.
